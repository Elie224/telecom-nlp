Méthode. Posts publics en français collectés sur X, nettoyés puis classés automatiquement par le modèle twitter-xlm-roberta-base-sentiment-multilingual. Les sujets sont détectés par mots-clés. Les résultats sont indicatifs : le modèle se trompe environ une fois sur trois (surtout sur les messages neutres) et l'échantillon ne représente pas toute la clientèle. Aucun texte de post n'est publié ici, seulement des statistiques agrégées : stats_par_jour.csv, stats_sujets.csv.
