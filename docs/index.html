Méthode : collecte de posts publics sur X, nettoyage, puis classification automatique (modèle cardiffnlp/twitter-xlm-roberta-base-sentiment-multilingual). Les résultats sont indicatifs : le modèle fait des erreurs (environ 62 % d'exactitude mesurée), surtout sur les messages neutres, et l'échantillon ne représente pas toute la clientèle. Aucun texte de post n'est publié ici, seulement des statistiques agrégées. Données : stats_resume.json, stats_par_jour.csv.
